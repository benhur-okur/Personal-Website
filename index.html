ReelVocab — Understand the English that dictionaries miss

A YouTube vocabulary layer for expressions whose meaning cannot be guessed word by word.

A Chrome extension that analyzes English YouTube captions and explains idioms, phrasal verbs, slang, and shifted meanings in their exact context. It is being prepared for its first Chrome Web Store submission.

  • Context-aware selection: prioritizes expressions whose meaning cannot be inferred word by word.
  • Secure BYOK architecture: model calls run in the service worker and the API key never enters YouTube's page context.
  • Guarded output pipeline: handles varied caption formats and rejects unsupported suggestions through schema validation and six deterministic gates.

Vocabify — Learn English from the scenes you love

The dictionary tells you what a word means. A scene tells you what it means here.

A mobile app for learning English through short scene clips. Each card pairs one expression with the moment it is spoken, then reveals its meaning and nuance in that specific context.

  • Scene-level meaning: every clip and explanation is tied to the expression's actual subtitle segment.
  • Review inside the feed: self-assessment schedules expressions to resurface naturally instead of creating a separate study queue.
  • Server-controlled scoring: row-level security and a two-encounter rule protect points from client-side manipulation.

AutoEDA — Intelligent Data Quality Analyzer

A web platform for safe, human-approved data cleaning on tabular datasets. The core design principle is Human-in-the-Loop: the backend exposes cleaning actions only after the user explicitly approves them — enforced at the API level via a typed approved_actions payload. Original files are never overwritten; every operation produces a versioned output alongside an automatic Before/After statistical report.

  • Non-destructive by design: cleaning writes to a separate output path — original data is always preserved.
  • Human-in-the-Loop at the API level: the /execute endpoint only processes actions the user has explicitly confirmed.
  • Async pipeline: Celery + Redis offloads heavy Pandas operations so the FastAPI event loop stays unblocked.

IUE Graduation Project I · FENG 497

preScan — Breath-Hold Event Detection from Video

An offline research prototype that detects meaningful breath-hold events in front-facing video. A MobileNetV3-Small backbone processes 15-frame windows; temporal pooling, thresholding, and minimum-duration filtering convert window probabilities into start, end, and duration segments.

  • Video-only pipeline: works with standard front-view MP4 recordings and requires no dedicated sensor.
  • Subject-aware evaluation: developed on 24 videos from 6 subjects, with LOSO used to expose leakage and generalization issues.
  • Reproducible offline demo: a local Streamlit interface runs inference, visualizes probabilities, and exports detected segments.
