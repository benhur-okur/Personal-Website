Vocabify — Learn English from the scenes you love

The dictionary tells you what a word means. A scene tells you what it means here.

Vocabify is a mobile app that teaches English through short scene clips. Every card is one expression and the one clip where it's spoken — you hear it, decide whether you knew it, and only then does the app reveal what it actually meant in that moment. No word lists, no dictionary definitions stripped of context, no guessing which of six senses was the right one.

  • The line on screen is the line you hear: each card's clip is cut to the expression's own subtitle segment plus the one before it — a guarantee locked down by tests, not by hand.
  • Meaning first, definition never: the app explains what the expression means in that scene, including the nuance a dictionary entry would flatten.
  • Review built into the feed: one honest self-assessment — I knew it · Not sure · New to me — schedules the expression, and due ones resurface inside the normal feed instead of a separate chore screen.
  • Scoring the client can't touch: points are written only by the server, with row-level security and a two-encounter rule that closed a real farming exploit found in production data.

AutoEDA — Intelligent Data Quality Analyzer

A web platform for safe, human-approved data cleaning on tabular datasets. The core design principle is Human-in-the-Loop: the backend exposes cleaning actions only after the user explicitly approves them — enforced at the API level via a typed approved_actions payload. Original files are never overwritten; every operation produces a versioned output alongside an automatic Before/After statistical report.

  • Non-destructive by design: cleaning writes to a separate output path — original data is always preserved.
  • Human-in-the-Loop at the API level: the /execute endpoint only processes actions the user has explicitly confirmed.
  • Async pipeline: Celery + Redis offloads heavy Pandas operations so the FastAPI event loop stays unblocked.

IUE Graduation Project I · FENG 497

preScan — Breath-Hold Detection from Video

A deep learning system that detects and classifies breath-hold events from front-facing video recordings. The pipeline runs a temporal sliding-window CNN (MobileNetV3-based) over video frames to segment three states — normal breathing, inhale-hold, and exhale-hold — frame by frame, without any dedicated hardware or sensors.

  • No special hardware: works on a standard webcam recording.
  • Rigorous validation: Leave-One-Subject-Out (LOSO) cross-validation across 6 subjects.
  • Interactive UI: Streamlit dashboard for real-time parameter tuning and inference.
